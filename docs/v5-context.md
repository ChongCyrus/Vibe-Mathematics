## 按需协议
新建或恢复成员时，在研究所生成并核验 `Shared/Protocol.md`（协议版本 1）。手册包含完整角色章程、原有字段目录、阶段导航、计算归档、流程反馈和论文排查；身份、职责、写入边界、证据纪律和手册位置常驻。写入或读取核验失败时，采用完整旧章程和完整提示，并在日志及成员提示中报告降级原因；不发送不可读手册的链接。
普通研究、心跳和任务轮展示数学进度、成果卡、消息、任务完成及阻塞操作和简短协调入口；院士另有分派与督办。会议展示发言、举手、邀请和结题判断；验证展示独立判断、理由和已启用的形式化字段；论文撰写、互审、定稿保留专用回执。解析器仍接受未列出的原有合法字段，权限检查继续生效。论文排查和流程反馈教程移入手册；论文排查在论文阶段提供。计算提示仅保留可用引擎、证据路径、修改后重跑与近似声明。

## 摘要与真实压缩
压缩准备时，成员在原有 `progress` 中记录目标、定义与假设、已建立结论及来源、未完成推导、失败路线及范围、下一步和完整材料位置。处理回执前冻结本轮压缩需求，回填低占用率不能取消已触发需求；先确认研究进度写盘，再调用该成员宿主的压缩服务。写盘失败不主动压缩，下一轮提示保存失败。异常回执处理也不主动压缩。
`compacted:true` 只表示提交了摘要。它不重置真实压缩计数，不把占用率设成 15%；宿主返回有效、非空且未明确失败的结果才重置计数。服务缺失、空返回、明确失败和异常分别诊断，完整日志保留，研究继续；至少间隔 `compactAfterRounds` 个完成回合再尝试。缺少 `contextPct` 时不生成估计，状态视图为 `null`，已有估计保留。成功压缩也不改写成员估计。
`members[].context` 为会话诊断：`estimateSource` 区分 `unknown` 与 `member-estimate`；`lastSummarySaved` 区分未提交、成功和失败；`lastProgressSaved` 为最近回执进度写盘结果；`lastCompaction` 为 `not-attempted`、`checkpoint-not-saved`、`unavailable`、`not-executed`、`failed`、`error` 或 `succeeded`；另有 `completedRounds`、`roundsSinceCompaction` 和 `lastAttemptRound`，只统计收到结束回执的回合；启动或投递尝试不能提前消耗重试间隔。这些字段重启后重置，不增加持久化格式。恢复种子只提供完整研究日志和成果卡导航，不截取最后 4,000 字作为证明替身。

## 工具说明、方法与兼容
修改前的 41 项完整说明、原参数结构和合法样例冻结在 `prompt-corpus-v5/baseline-tools.json`，说明总计 15,061 字符。当前 42 项（含新帮助工具）总计 2,660 字符，减少 82.34%，单项均不超过 240 字符；参数结构没有为预算裁剪。短说明保留用途、角色、前置条件、证据纪律、任务修订号与异步作业尚未通过等约束。完整方法在 `vibe-math-v5.js` 注册时由旧说明、步骤和样例组成，参数直接引用同一注册表；`Shared/Protocol.md` 引用同一份内容。
`vibe_v5_tool_help` 每次只返回指定工具的 `{ok,tool,version,parameters,instructions,examples}`，可在创建研究所之前使用，不依赖手册写盘。方法版本由参数、完整说明和样例的内容哈希生成。先调用帮助，再按真实返回的身份、任务修订号与路径调用业务工具；样例中的任务和路径不是固定值。

```json
{"tool":"vibe_v5_task_update"}
```

此参数对象提交给 `vibe_v5_tool_help`。首次查阅检查固定覆盖 `vibe_v5_set`、`vibe_v5_task_update`、`vibe_v5_assign`、`vibe_v5_propose_verify`、`vibe_v5_lean_run`、`vibe_v5_lean_archive`、`vibe_v5_lean_lib`、`vibe_v5_lean_job`、`vibe_v5_feedback`、`math_computation`。原有权限检查优先；无权限仍返回原错误，有权限但未读返回 `V5_TOOL_HELP_REQUIRED` 及指定帮助参数，不写业务状态、不计算、不安排任务。未知方法返回 `V5_TOOL_HELP_UNKNOWN`，不会产生阅读记录。
阅读记录只属于取得方法的真实代理会话和工具版本，不允许其他成员代读；会话重建、宿主重启或框架确认真实压缩成功后重新查阅，失败压缩与 `compacted:true` 摘要不清除记录。方法或参数改变使旧记录失效。记录仅在内存，不增加持久化状态。简单工具、人工斜杠命令、框架内部操作和原 JSON 回执没有阅读门槛；模型仍可返回全部旧合法字段。自定义工具白名单若允许复杂工具，须同时允许 `vibe_v5_tool_help`；本批不会自动扩大用户设置的工具权限。
测试发现旧 `vibe_v5_lean_archive` 的 `kind="proof"` 分支忽略 `run:false`，仍会编译或入队。本批保留该业务行为，并在短说明和方法中明确限制：仅 `def/lemma` 的 `run:false` 保证只归档；只保存项目证明时直接保存 `Formal/<target>.lean` 并注明未编译。任何入队、索引或阻塞记录均不能冒充通过凭据。
静态与行为覆盖见 `tests/v5-tool-help.test.mjs`，包括无副作用拒绝、读后调用、错工具、跨成员、权限优先、重建与重启、真实压缩后重新查阅、参数版本变化、任务冲突和计算失败。真实模型对照短组完成 24/24、完整组 23/24，所有成功复杂操作都有同会话的先前帮助返回；含试跑与补测的保守费用合计 6.580598 元。方法已提供不等于模型已理解；完整轨迹、评分、限制和复现步骤见 [工具对照报告](v5-tool-evaluation.md)。

## 独立数学模型对照步骤（仍未运行）
第一批实测：短章程样本最长 728 字符，普通研究及心跳框架说明减少约 81%–83%；提示词检查 568 项、行为检查 621 项、计算检查 117 项、自驱动检查 95 项通过，故障注入检查 39/39 与 5/5 检出预期错误。第一批全量入口的快速数量断言预期 24、实际 25，临时入口修正计数后 199 项得到 174 通过、25 失败；不据此宣称全量通过。第二批增加工具行为套件后，原入口预期 24、实际 26；临时入口收集 200 项得到 179 通过、20 失败、1 中止，单独复查及真实发布打包结果见工具对照报告。临时目录均放在仓库外；曾因仓库内临时目录递归复制导致空间耗尽，该次结果不作为产品缺陷证据。仓库全量门禁仍未通过，不影响保留并报告本批单项与模型测试的真实结果。

使用 [GSM-IC 官方数据](https://github.com/google-research-datasets/GSM-IC/blob/main/README.md) 的 `GSM-IC_2step.json` 和 `GSM-IC_mstep.json`：它们的 `new_question` 包含干扰信息，`answer` 为标准答案。实验前固定数据提交号、两文件 SHA-256、模型的精确版本、采样参数、工具及输出预算，保存不可变清单。不得把答案或干扰类别注入模型。依次拼接两个文件的原始数组，按下列方法固定抽取 20 条并保存题目索引；若同一个 `original_question` 出现多次，分析时注明相关性，不能把重复试次当作独立题目。

```python
import json, random, hashlib
from pathlib import Path
files = [Path('GSM-IC_2step.json'), Path('GSM-IC_mstep.json')]
pool = []
for file in files:
    raw = file.read_bytes()
    print(file.name, hashlib.sha256(raw).hexdigest())
    pool.extend((file.name, i, row) for i, row in enumerate(json.loads(raw)))
chosen = random.Random(42).sample(pool, 20)
schedule = [(q, repeat, group) for q in range(20) for repeat in range(3)
            for group in ['old', 'new']]
random.Random(42).shuffle(schedule)
Path('sample.json').write_text(json.dumps(chosen, ensure_ascii=False, indent=2), encoding='utf-8')
Path('schedule.json').write_text(json.dumps(schedule), encoding='utf-8')
```

共 120 次调用，每题每组重复三次，按清单随机交错，每次用全新会话。旧组从冻结语料提取研究员章程及普通研究框架说明，新组从新语料提取同角色、同阶段说明；移除两组样本中的原问题、消息和任务，均替换为完全相同的 `new_question`。固定所名、成员身份和工具清单；保留组内原有章程与回执要求，不附加答案提示。先保存两组最终输入及哈希，人工核对差异只来自框架说明，再运行。手册若可读，两组均提供相同文件访问能力，记录实际读取的内容与额外词元；不读手册的试次和读手册的试次分别报告，避免隐藏检索成本。
正确性按最终明确答案与标准答案比较（允许等价数值及单位，不因推理格式扣正确分）；无法得到明确答案记错误。将模型输出匿名后，由不了解分组的评阅者检查是否将无关人物、数字或制度说明作为数学推理依据，统计事件次数并保存引用片段；纯粹提及无关信息不计入。协议错误按 JSON 可解析、字段合法和权限合规逐项记，不把数学错误混入协议错误。工具错误和网络失败单列，重试记录保留，不能静默删试次。
