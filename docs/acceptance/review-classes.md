# 深度检查的【类别清单】——「全面」的定义

> ★★★ **这份文件存在的理由**：目标 5 的判据是「**直至连续一轮检查不再发现新问题为止**」，
> 而 **"全面"一直是个形容词** —— 每轮扫的东西不同，"零发现"就永远不能算"全面零发现"。
> ★ **所以先把"全面"写成清单**：★ **一轮检查如果【按本清单逐类跑完且零发现】，那就是判据达成。**
> ★ 这是一次**自我设限**：清单之外的东西不算"没查"、也不算"查了"——★ **它只是不在这个判据的范围内，★ 并在 §4 显式列出**。

## §1 用法

★ **跑一轮检查**：★ 从 §2 逐类跑，★ 每类必须给出 **"扫了什么 / 判据 / 命中数"** 三件东西。
★ **判据达成**：★ **§2 全部类别命中 0**，且 §3 的"每条发现都要有归处"成立。
★ **"命中"的定义**：★ 一条**能指向 `文件:行` 或命令输出**的缺陷。
★ **不算命中**：★ 风格偏好／★ 清单本身之外的类别／★ "可以更好"但没有具体缺陷的。

## §2 类别（★ 全部来自本阶段九轮的实际扫描，★ 不是凭空设计的）

### A. 断言质量（★ 假绿）
| ★ | 判据 |
|---|---|
| ★ A1 | 不存在恒真断言（`\|\| true`／`ok(true, …)`／`!X === false \|\| true`） |
| ★ A2 | 不存在按**坐标**定位的断言（硬编码行号） |
| ★ A3 | 每条 mutation 都**自证命中**（替换不改变文本 ⇒ 具名失败） |
| ★ A4 | 不把"报告"伪装成"门禁"：★ 报告型检查**没有断言**，★ 不是 `ok(true)` |

### B. 静默丢东西
| ★ | 判据 |
|---|---|
| ★ B1 | 所有 `list`／`summary` 类回执带 `total`／`returned`／`truncated`（★ 或等价标记） |
| ★ B2 | 未知名（面名／action／设置键）⇒ **具名拒**，★ 不静默忽略 |
| ★ B3 | 截断必自报；★ 补 `limit:0` 或等价"取全部" |

### C. 声明与实现的一致性（★ 半成品实现）
| ★ | 判据 |
|---|---|
| ★ C1 | **有接口无实现**：★ 声明的对外方法没有空实现/占位 |
| ★ C2 | **有声明无读点**：★ 设置键要么有读者，★ 要么标 `planned` |
| ★ C3 | **读了无效果**：★ 有读者但只回显 ⇒ **必须自曝**（如 `initiativeEffect:'display-only'`） |
| ★ C4 | **有错误码无抛出点**（双向）：★ 登记≠已实现；★ **已抛未登记**也是缺陷 |
| ★ C5 | **有工具面无 handler**：★ 每个面每个 action 有分支，★ 且分支非空实现 |
| ★ C6 | **声明了域就必须执行**（enum／number min/max／pattern／元素类型） |

### D. 具名拒绝
| ★ | 判据 |
|---|---|
| ★ D1 | `VMU_*` 具名拒 **`hint` 不许为 `null`** |
| ★ D2 | `hint` 必须是**可走的动作**，★ 不是只有名词 |
| ★ D3 | 坏输入 ⇒ **具名拒**，★ **不是 `TypeError`／裸 `Error`** |
| ★ D4 | 拒绝的理由必须**说清处境**（如"该会议在服务注册表，★ 本 action 只读原语"） |

### E. 共享可变状态
| ★ | 判据 |
|---|---|
| ★ E1 | 跨调用复用的对象**不原地改**（copy-on-write） |
| ★ E2 | 同一概念**只有一份权威存储**（★ 不出现两套账） |

### F. 提示词与实际
| ★ | 判据 |
|---|---|
| ★ F1 | 提示词**不教不存在的工具/动作/回执字段** |
| ★ F2 | 提示词里的**参数名与真实面一致** |
| ★ F3 | 同源块与 wire **不矛盾**（★ 含 ptc 呈现方式） |
| ★ F4 | 静态工具清单里**没有不可用的工具**，★ 且 wire 里的工具**都出现** |

### G. 生命周期
| ★ | 判据 |
|---|---|
| ★ G1 | 注册的 listener/hook **有可撤销句柄**，★ 且**卸载路径真的调用它** |
| ★ G2 | 无可撤销手段时 ⇒ **具名记录**（如 `unrevokable`），★ 不静默 |

### H. 文档与实际
| ★ | 判据 |
|---|---|
| ★ H1 | 能派生的数字**一律派生**；★ 手抄的会漂移的数字不许留在文档里 |
| ★ H2 | **docs 的动作清单 ⊇ 真实 enum**，★ 且反向不许多（★ 已有门禁 `audit-doc-actions`） |
| ★ H3 | 历史上混用的词（★ 消费者 vs 读点）★ **以 `docs/01 §1.4` 为权威并互相指认** |

### I. 打包与归档
| ★ | 判据 |
|---|---|
| ★ I1 | **不发货物不该出现在 `files`／`exports`／`installer`** |
| ★ I2 | `npm pack` **无 declared-but-missing**；★ 差异可解释 |
| ★ I3 | 归档后**运行时按旧根读取 = 0** |
| ★ I4 | 发货的东西**能跑**，★ 不能跑的**必须文档化**（★ 已记：53 个测试依赖不发货的 archive） |

## §3 每条发现的归处

★ 任何一条命中都必须有归处：★ **已修**（★ 给 `commit`）／★ **已登记为 `planned`**（★ 给键名）／★ **已文档化**（★ 给文档位置）／★ **明确不修并说清理由**。
★★ **"先记下来"不算归处** —— ★ 那会变成屎山。

## §4 显式【不在】本判据范围内的

★ 本清单**不覆盖**以下（★ 明确写出来，★ 以免"零发现"被误读成"全都查过了"）：
1. ★ **真实宿主下的行为**（★ `ctx.on` 是否被宿主代管、★ npm 安装后的清理、★ DSH 版本差异）——
   ★ 这些**只能用真机验证**，★ 属目标 6／7 的范围。
2. ★ **并发与负载下的时序**（★ 如 `run-tests` 的并发超时）—— ★ 属基础设施，★ 已单独处理（树杀 ＋ 实测预算）。
3. ★ **性能**（★ 冷启动、★ 内存、★ 执行时间）—— ★ 本阶段未做基准测试。
4. ★ **安全审计**（★ 注入、★ 越权、★ 密钥处理）—— ★ 除本清单 D 类与"票权"外未系统开展。
5. ★ **未落地的设计**（★ `planned` 键的**实现**）—— ★ 它们是**声明未接线**，★ 不是缺陷。

## §5 这份清单的自检

★★ **它必须能被【反着用】**：★ 若某一轮在某一类**真的零命中**，★ 那份"扫了什么/判据/命中 0"就是**该类达标的证据**；
★★★ **若某一类【扫不动】**（★ 缺夹具／★ 缺环境），★ **必须写明缺什么** ⇒ ★ **不许用"看起来没问题"填补**。

## §6 本阶段（phase 11）的实测补记 —— ★ A2／A3 与已修清单

> ★ 本节是**phase 11 复扫的实测**，★ 补在九类判据之后：★ **A2／A3 是上一阶段留下的两个覆盖边界**（"没看那么细"），★ 这一轮真的量了。

### §6.1 A2（按坐标定位的断言）—— **实测 0 条，类达标**

★ 全仓 `tests/*.mjs` 搜 `line: N` / `.line ===` / `lineNo ===` / `at line N`，★ **命中都不是源码行号断言**：
- ★ `audit-declaration-criterion`：`hitFingerprint({ file, line: 7 })` 是**纯函数的入参**，★ 而且断言**行号不进入指纹** —— ★ 它是**反 A2** 的证据（★ 证明坐标不影响判定）
- ★ `audit-doc-line-refs`：`docLine` 是**在文档里定位那条引用**用，★ 不是断言源码位置

⇒ ★ **A2 结论：无此缺陷。** ★ 依据是上面那条搜索命令的输出（★ 可复跑）。

### §6.2 A3（mutation 自证命中）—— **实测：53/120 扫描式门禁有自证，67 条没有**

★ 量的方法：★ 取 `tests/audit-*.mjs`（★ 不含 `.mutants.`）**120 个**，★ 逐个判"文件里有 `--selftest`"**或**"有同名 `.mutants.mjs`"。★ 结果：★ **53 个有**、★ **67 个两个都没有**。
★ 另有 **36 个 `.mutants.mjs`**、**45 个带 `--selftest`** 的文件。

★★★ **这 67 条是【已知残余】，不是【已清】。** ★ 按判据 A3，★ 它们**无法自证"0 命中"不是判据没匹配到东西** —— ★ 而本仓为此付过三次学费（★ `docs` 里已记：反斜杠路径、要求引号、只收 `.js`）。
★ **不宣称 A3 达标。** ★ 正确的说法：★ **A3 的已知成员里 53 条已有自证；67 条未加，是明确的待办。**
