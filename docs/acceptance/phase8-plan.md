## §2 ★★ 目标 A：把工具表按角色收窄，★ 并让"提示词说的"与"工具表发的"不可能再漂移

### A1 ★★★★ v5r 声明 `toolFaces`
★ 把三段提示词里的**角色工具清单**变成 **manifest 的 `toolFaces` 声明**：
```js
toolFaces: {
  chair:  { allow: [ …院士那 19 个… ] },
  member: { allow: [ …研究员那份… ] },
  temp:   { allow: [ …临时工那份… ] },
}
```
★ **能力已存在**（★ `applyMemberToolFace` ＋ `applyPackToolFaces` ＋ `validatePack` 校验）⇒ ★ **只需声明** ✓

### A2 ★★★★ 一条**同源断言**（★ 这是本目标的判据核心）
★★ **断言：★ 某角色提示词里列出的工具集合【等于】该角色 `visibleToolsOf` 的实际集合**（★ 双向包含，★ 给差集）✓

### A3 ★★★ 零机制与不伤害
★ **不声明 `toolFaces` ⇒ 行为与今天完全相同**（★ 零机制）✓
★ **已落座者与后落座者都要覆盖**（★ 上一轮实现是"只对当前 live 成员生效"，★ **要确认新落座者也拿得到**）✓
