## 纪律（沿用；R21 新增）

- **★ 新：遮蔽型缺陷** —— **"文档化的东西恰在开始生效的那一刻坏掉"**（`config.packs` 第一次做事就打死会话）⇒ **"它以前一直是好的"不等于"它现在好"**；**零机制/空配置下的绿灯不覆盖"第一次真正启用"那条路径**。
- **★ 新：实验设计先问"这两臂能否分开"** —— arm B/D 的"会话能起"与 H1 **同真** ⇒ **跑它会得到一个"看起来确认 H1"的假确认**；**不具判别力的对照不许跑**（省的不只是钱，还有"假确认"）。
- **★ 新：模块不得自造公开码**（代码侧就有牙）；出路＝**复用语义相符的已登记码**，或**由 docs 属主登记**。
- 既有：门禁必须有牙／判据与环境一致／**门禁必须读事实所在的那种文本**（注释≠代码）／"我没找到"≠"它不存在"／**回执说成功必须与事真的做了分开断言**／两向断言必须让被判定的那一行真的走红／读数必须绑版本且在最后编辑后重跑／**悬空清单机制化**／`JSON.stringify(<Promise>)="{}"`／会话日志是多帧的／量具坏了会给自信的错误答案。
- 轮末由 Lead 统一 `update-doc-counts → regen-all → generate-wiring-index → T0 → T1 → commit → push`；**不发布**。
