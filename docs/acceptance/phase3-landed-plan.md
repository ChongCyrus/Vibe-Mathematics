## 1. ★★ 先说一条结构性裁定：**`docs-landed` ≠ `docs/acceptance/`**

★★ **`docs/acceptance/` 是【过程证据】**（逐轮报告、审计、裁决、反例），★ **`docs-landed` 是【面向使用者的定稿文档集】**。
⇒ ★ **裁定**：★ 定稿**只收**"**当前为真、且使用者需要**"的内容；★ 过程证据**以引用形式出现**（"此结论的取证见 `<file>`"），★ **不整卷搬入** ✓
★ 理由：★ 过程证据里**必然包含已被推翻的前提与已修的缺陷**；★ 它们**本身没有错**（那是当时的读数），★ **但放进定稿就会变成"与实际不符的内容"** ⇒ ★ 这正是用户明令排除的 ✓

★ 因此 `docs-landed` 的来源分三类：
| 来源 | 收不收 | 说明 |
|---|---|---|
| `vibe-math-vmu/docs/00–29`（正文卷） | ★ **收，并按当时实现校正** | 这是既定的使用者文档面 |
| ★ **根哲学与判据类**（`01-§1` ＋ 本阶段裁定） | ★ **收** | 它们定义"什么算对" |
| ★ **本阶段的裁定与最终口径**（见 §3） | ★ **收（提炼后）** | 不是整篇搬，而是**结论入卷、取证引用** |
| ★ 逐轮报告／审计过程／反例 | ★ **不收**（引用） | 属过程证据 |
