## 1. ② 跨文件四类覆盖面（本轮的实质改动）

`scripts/generate-vmu-settings-table.mjs` 的 `IMPORTERS` 只认具名 `import { … } from`；本轮补齐四类：

| 形式 | 实现 | 覆盖 |
|---|---|---|
| ① 命名空间 | `import * as N from '…'` ⇒ `N` | ✓ |
| ② 默认 | `import D from '…'`（也含 `import D, {…} from '…'`） | ✓ |
| ③ 再导出 | `export { A, B as C } from '…'` ⇒ `A`／`C` | ✓ |
| ④ 动态 | 先一次性筛出**含 `import(` 的文件**（`DYNAMIC_FILES`），再**按名字**查该文件里是否有 `.NAME` | ✓（名字可推时） |

- ★ **`export * from '…'`**：**名字在这一行上不可知** ⇒ 我**没有猜**，只把该文件标记为 `starReexport` ⇒ **这部分仍写"没核"**。
- ★ **"看不见"仍不写成"没人读"**：四类都查不到 ⇒ 仍是 `未接线`。
- ★ **本树按这四类核过：新增命中 0 处** ⇒ 滚动数不变 **`1108 wired / 3 undetermined / 115`**（`--json` 实测）。⇒ ★ **"数字没变"也给了机制**：不是"没生效"，而是这四类在本树里没有对**未被遍历的列表**产生新证据。
