# dsh-vibe-math 2.8.6-local.2 — 本地兼容补丁

## 概述

基于 2.8.5 与第一阶段加载热修复的本地验收版本，目标宿主为实际安装的 DSH 0.2.2-rc.1。未发布 npm；保留四套框架的研究策略与用户数据格式。

## 新增

- 共享子代理兼容入口及准入、清理、四框架集成和环境解析回归。
- 普通 Node / Electron ASAR 测试前置解析及明确的缺失依赖诊断。

## 变更

- V2–V5 按能力选择旧 startContinuable 或现代 startActivation。
- V5 现代路径将完整冻结身份放在首轮任务前部；旧路径保持独立 persona 字段。
- 两个变异驱动从模块位置定位仓库；runner 加入四个明确的只读状态变体。

## 修复

- 修复当前宿主已移除创建方法导致的实际派发失败。
- 修复首轮原生 start/end 早于准入返回时丢失 Agent 或研究回复的竞态；按确切 childId 交接既有处理器，不重发事件。
- 观察 Activation result；关闭时取消并等待准入回滚、释放当前收据，并按原父对象与已知地址清理冷恢复任务。
- V5 成员解雇兼容现代 drainChildren，等待清理并保留错误传播。
- 继承上一阶段去除已移除 list-agents 子入口的加载修复。

## 兼容性与迁移

参数与持久化格式保留，未新增运行依赖。上游支持窗口及 testedVersion 历史元数据保留；本次真实验收结果单独记录。详见[宿主兼容说明](../HOST-COMPAT-0.2.2.md)。

## 已知限制

显式工具过滤请求在当前宿主会具名停止派发；V5 现代身份传递的提示层级与旧接口存在差异；现代首轮 caller 投递不会改变宿主冷恢复默认 parent 投递。

## 验证方式

运行[兼容说明](../HOST-COMPAT-0.2.2.md)中的独立回归、完整 runner、宿主注册表与构建检查。数学真实求解另行记录，区分源码修复、测试、构建、安装和内存运行状态。

## 依赖

无新增运行时依赖；沿用现有 Node 与 DSH 声明。
