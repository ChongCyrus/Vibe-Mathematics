## 关于本索引

- **2.7.0 之前没有英文版**：这些发布说明不会被机器翻译；上表每行的一句话就是对应中文文件的英文提示，
  细节请读链接的中文原文（英文读者请看 [`README.en.md`](./README.en.md)）。
- **2.7.0、2.7.1 与 2.7.2 已中英双语齐备**；自下一版本起，每个版本都同时提供两种语言，并同步更新本索引与
  [`README.en.md`](./README.en.md)。
- **版本号规则**：补丁版只含修复与**附加**响应字段；功能版新增能力。版本号由维护者决定，发布说明本身会写明
  这一次属于哪一类。
