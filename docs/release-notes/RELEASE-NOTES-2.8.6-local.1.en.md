# dsh-vibe-math 2.8.6-local.1 — Local compatibility patch

## Overview

Local validation build based on 2.8.5 and the first-stage preset loading repair, targeting the installed DSH 0.2.2-rc.1. This version has not been published to npm. All four research strategies and persisted data formats are retained.

## Added

- Shared subagent admission adapter and behavioral, lifecycle, four-framework integration and environment regressions.
- Explicit host prerequisites for ordinary Node packages and Electron ASAR installations.

## Changed

- V2–V5 detect the legacy startContinuable or modern startActivation capability.
- Modern V5 places the complete frozen identity before the first task; legacy V5 retains its separate persona field.
- Two mutation drivers locate the repository from their module URLs; the runner includes four explicit read-only status variants.

## Fixed

- Child admission no longer calls a removed host method.
- Native start/end events that precede admission return are handed to existing handlers after exact childId ownership registration, preserving the first Agent and reply without emitting duplicate events.
- Activation results are observed; shutdown aborts and awaits pending admission rollback, disposes active receipts, and drains known cold-resumed addresses using the exact original parent.
- V5 member retirement awaits modern drainChildren and preserves cleanup errors.
- The first-stage removal of obsolete list-agents subentries is retained.

## Compatibility & Migration

Parameters and persisted formats are retained with no new runtime dependencies. Upstream support-range and testedVersion metadata remain historical; local verification is reported separately. See the [host compatibility notes](../HOST-COMPAT-0.2.2.md).

## Known Limitations

Explicit tool filters stop admission with a named capability error on this host. Modern V5 identity content is preserved but occupies a different prompt layer. First-activation caller delivery does not override the host's parent delivery on cold resume.

## Verification

Run the focused regressions, full runner, native registry test and build checks in the [compatibility notes](../HOST-COMPAT-0.2.2.md). Real model mathematical acceptance is reported separately from source, test, package, installation and in-memory runtime checks.

## Dependencies

No new runtime dependencies; existing Node and DSH declarations are retained.
