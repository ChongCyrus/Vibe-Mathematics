# dsh-vibe-math 2.8.3 — 发布说明

> 上一版本：2.8.2。本版是**补丁版**，修两处 v5 的会议与定稿问题：**会议收束后到达的发言不再被静默丢弃**（改成具名的"会后补记"）；`force` 重启后 `paperEditor="office"` 的定稿拒绝会**说明原因**（计数已随新论文重置、需重新征询）。参数名与默认值、数据格式与目录结构**未变**，DSH 支撑窗口不变，**无需迁移**。

## 概述

- 成员的会议发言**不会再无声消失**：即使发言在会议收束（看门狗放弃停滞会议，或所办提前定稿）**之后**才到达，也会作为「**会后补记**」写进会议纪要，并在群聊里具名说明一次。
- 会议纪要**只增不覆盖**：先前发言者的内容一律保留。
- `force` 重启后的定稿拒绝**可解释**：响应新增 `restarted: true` 并写明 `forceReason`，消息直接告诉你"计数随新论文重置、重启前的消息/会议不再计入、请重新征询"。
- 文档明确：**`force` ＝ 一张新论文**（`consult` 的两个计数随之从 0 开始），因此重启后必须**重新**征询。

## 新增

- `vibe_v5_finalize_paper` 在因征询不足被拒时，响应新增 **`restarted`** 字段（布尔；该论文是否由 `force` 重启而来）。

## 变更

- 会议纪要新增一种条目：「会后补记」（`### <成员>（会后补记：该发言到达时会议已收束）`）——针对**会议已收束后**到达的发言；同一段文本重复提交只记一次。
- `V5_PAPER_CONSULT_REQUIRED` 的文案在 `restarted` 时追加重置说明（**行为逻辑不变**，只是把原因说清）。
- `docs/final-paper.md` §7 增补一条「`force` ＝ 一张新论文」的口径。

## 修复

- 症状：某位成员（真机实测中正是**会议的召集人**）的发言没有出现在会议纪要里——纪要在头部写着 `- 发言顺序: r-1 → acad`，正文却**只有 `### r-1`**；同一张论文的 `consult.meetings` 一直为 0，定稿被连续拒绝。原因：成员结束块里的 `input` 只认「**有活会议**」这一条路径，而会议一旦停滞会被看门狗收束，之后到达的发言**无处可去、静默丢弃**。现在这类发言会作为「会后补记」写入纪要（具名、去重、追加而非覆盖）。守卫：`tests/e2e-v5-round2.test.mjs`（`★ [real1004-minutes]`）、`tests/v5-institute-fixes.mutants.mjs`。
- 症状：`force` 重启论文后，所办按老流程定稿会被 `V5_PAPER_CONSULT_REQUIRED` 反复拒绝，而**提示里没有任何线索**说明"刚刚重启导致计数清零"（真机实测连续 **11** 次、只能靠成员自行推断）。原因：这一语义**只存在于代码里**，文档与拒绝文案都没写。现在拒绝会具名说明重置与"请重新征询"，文档也把「`force` ＝ 新论文」写清楚。守卫：`tests/e2e-v5-round2.test.mjs`（`★ [real1004-consult]`）、`tests/v5-institute-fixes.mutants.mjs`（**18/18** 具名红）。

## 兼容性与迁移

- 破坏性变更：**无**。
- 纯新增：`restarted` 响应字段；纪要里一种新的条目类型。
- 迁移：无需迁移；既有 `paper.meta.json`、会议纪要与目录结构不变。
- DSH 支撑窗口不变（见 `package.json` 的 `engines.dsh`）。

## 已知限制

- **非标准位置的 TeX 仍不会被自动发现**：默认探测只覆盖 PATH 与文档化的常见安装根；装在其它目录请用 `paperLatexCommand` 指绝对路径。
- 随包套件**不覆盖宿主层行为**（例如「中断后调用方被丢弃」），这类行为需要真机才能观察。
- **根代理提问会阻塞整所流程**（运维注意项，不改产品）：答复到达前其余流程停摆；长跑时请把问题与验收条件一次说清。详见 [`slv-playbook.md`](./slv-playbook.md) §5。
- 会议「因长时间无新发言被看门狗放弃」之后，纪要里会留下放弃标记；**放弃前的发言仍保留**，之后到达的发言进「会后补记」。
