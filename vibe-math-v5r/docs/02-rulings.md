# 第 02 章 · 裁定定稿

**本旨**：把每条已定裁定与其硬约束/可调政策一次说清，冲突时以本章为准。

**本章权威性**：本章是全部已定裁定（R1–R10／D1–D10／G1–G5／U3–U5）的唯一权威；与本章冲突的任何其它说法一律作废。

> 本文件把依「贴合哲学 ＋ 守住红线 ＋ 最佳实践」作出的全部裁定**固定为 durable 定稿**。**裁定权归用户**；本文件**不自行改判**，只做转写与一致性标注。
> **只读既有稿件**（PHILOSOPHY／GAPS／DECISIONS／SPEC），**本文件是唯一新建文件**，未修改任何既有稿件。
> 业务层语言，**不含**实现细节（无命令、参数、错误码、守卫、行号、代码）。

## 1. 定稿摘要（≤300 字）

本文件是会议平台的**裁定定稿**：把 DECISIONS 第 3 节 的 A 案按设计裁定落定为 D1–D10 十条已定规则，并给出 C1、C3、C5 三条硬口径。核心取向有三：其一，**框架只推荐、不驱动**——绝不自动散会、自动收束，静止时最多提示一次并说明「谁在等谁」；其二，**沉默绝不等同同意**——只记「未表态」，且未表态不提升结论强度，任何「沉默＝无异议」通道一律禁止；其三，**门槛与聚合分层**——意见收敛可用「m 一致⇒定论，否则取平均并更新概率」，程序性表决未达门槛一律记「未决」，不得用平均替代表决结论。同时落定：默认记名、不记名仅限敏感事项且留档、主持不额外加权、少数意见强制入档并作复议触发、引用限同一会议且私聊内容须先补记到群聊或会议、真值仍由验证制度裁定。**未决／观察项**：DECISIONS 第 4 节 的矛盾与残余漏洞我**未能逐条核对**（见 第 4 节），另有三项留给日后（档案检索、复议流程细化、专业术语与纪要模板的统一）。

## 2. D1–D10 裁定表（**已定**；对应 D1–D10）

| # | 问题 | 裁定（已定） | 理由（现实依据／红线） | 硬约束或可调政策 |
|---|---|---|---|---|
| D1 | 谁主持、可否代行 | **仅院士主持；代行须显式指定** | 本所主持＝主办方（院士），组织基础自洽；代行若不显式化，事后无法追责 | **硬约束**：非院士不得自任主持；代行须在会议记录中明确写明 |
| D2 | 可否「全体推翻主持」 | **不设**该重型通道；**程序异议留痕** | 「开会推翻主持人」在代理场景成本过高；但程序裁决必须可救济 | **硬约束**：成员可提程序异议并要求主持给出理由；异议与理由一律入档 |
| D3 | 到场与分母语义 | 到场＝**在可表决集合内且能应答**；**未答不计分母、不算反对，且名单必列**；弃权计入已投但不计选项；**沉默计入在册、不计入已表态** | 没有到场口径，「m 人一致」会被实际到场人数偷偷改写；未答被算成反对会制造假反对 | **硬约束**：清点必须列出未答名单；未表态与无异议严格分离 |
| D4 | 门槛未达与无限延长 | 未达门槛＝**未决**；平票须**事先写明**；反复未达走**降级出口**；**延长需动议＋多数**，且受**次数＋总时长双上限**；到期落**预设出口**（按规则取平均并标「未定论」，或归档） | 「没有结论」是合法结果，必须事先写明，否则系统会自行编一个；无限延长会拖死 run | **硬约束**：不得静默续期；**可调政策**：双上限的具体数值与预设出口的选择 |
| D5 | 少数意见与复议 | 少数意见**强制入档**并作**复议触发**；复议须由**当初胜方之一**提出，且**限同一会议** | 少数意见是纠错的第一手材料；不设门槛会导致无限复算 | **硬约束**：少数意见一律入档；**可调政策**：复议的具体发起时点 |
| D5a | 无胜方情形的复议发起 | 结果为「未决／取平均（含标注未定论）／归档」等**无明确胜方**情形时，复议可由**任一参与该次表决者**提出（**含持少数意见者**）；其余情形（有明确胜负）仍**限于当初胜方之一**。两种情形均**限于同一会议**，并沿用**只升不降**的门槛（U3） | 补 D5 漏洞：无胜方时复议权被架空，与「少数意见作复议触发」的立法目的相抵 | **硬约束**：该情形下不得以「无胜方」为由拒绝受理复议 |
| D6 | 引用边界 | 引用**仅限同一会议内**；跨会议**只引上次决议**；**私聊内容不得作为引用来源**（须先补记到群聊／会议）；散会后材料可进附录但**须标注** | 引用无限制会造成引用链爆炸与语境丢失；私聊不可审计 | **硬约束**：引用只带摘要＋稳定指针，不搬原文；超界引用须标注来源与补记位置 |
| D7 | 流程分级与简流程 | **建议节奏但不强制**；**简流程不得产出实体定论** | 仪式过重会拖慢例会；但简流程若可产出定论，等于绕开全部门槛 | **硬约束**：简流程结论不得当作决议；**可调政策**：何为「正式议题」的判定习惯 |
| D8 | 列席／受邀／临时工 | 可被**引用**；经主持允许**可发言**，但**永不表决** | 把「信息来源」与「表决权」分开，才能安全吸收外部意见 | **硬约束**：非成员一律无表决权；发言须经主持允许 |
| D9 | 辩论的作用与广播 | 辩论只**收敛意见并记录理由**；**真值仍由验证制度裁定**；广播须说清「依据规则、因为什么、所以结果」 | 辩论若被当成真值来源，就越过了验证制度的边界 | **硬约束**：辩论不得宣布真伪；广播三要素缺一即不合格 |
| D10 | 框架在会议中的角色 | **只建议**——**绝不自动散会／自动收束**；推荐**一句一条**、可拒绝、不反复重申；静止时**最多提示一次**并列出「**谁在等谁**」 | 「框架只推荐不强迫」是本平台的核心红线；自动收束等于替人开会 | **硬约束**：不得自动结束会议或宣布收束；**可调政策**：提示的措辞与静止判定 |

**与 DECISIONS 的出入／需复核（第 1 节 计数：2 条）**
- **出人 1（D2）**：DECISIONS 第 1 节 第 16 条对「主持裁决与申诉」记的是「变形纳入（全体表决推翻主持不纳入）」——与本文件的 D2 **一致**；但 DECISIONS **未**写明「程序异议须由主持给出理由」，本文件按设计定稿**补齐**该要求 ⇒ 属**新增要求**，需定稿确认措辞。
- **出人 2（D5）**：「复议须由**当初胜方之一**提出且**限同一会议**」在 DECISIONS 第 1 节 的 K2 条只写到「少数意见强制入档并作为复议触发之一」，**未**限定发起人与生效单位 ⇒ 本文件按设计定稿**收紧**，并**已确认定稿**（收紧是为**防滥诉**，**不改变**少数意见强制入档的义务——两者是两件事：**入档义务不因收紧而减弱**）。

**2.3 「不纳入」的 5 处——理由与替代安排**
1. **GAPS 15 主持权轮值／选举主持**：不纳入。理由：本所主持＝主办方（院士），无选举轮值的组织基础。替代：以「主持不额外加权 ＋ 程序异议留痕」承担监督功能（C5、D2）。
2. **GAPS 6 打包审议**：不纳入。理由：代理场景徒增轮次。替代：允许**拆分**表决；需要整体性时以一次「合并审议」表态处理，但要拆开记账。
3. **GAPS 7 完整修正案表决链**：不纳入。理由：逐条修正表决对代理过重。替代：友好修正直接并入；实质修正走一次表态（D6 的引用规则保证可追溯）。
4. **GAPS 16 「全体表决推翻主持」**：不纳入。理由：成本过高。替代：程序异议＋要求主持给出理由，两者留痕（D2）。
5. **GAPS 20 固定提前时限**：不纳入。理由：固定小时数在代理场景不现实。替代：临时会给一次**可应答窗口**，例会按固定节奏（D4 的双上限仍适用于延长）。

## 4. 红线与硬约束清单（合订）

| # | 红线／硬约束 | 违反会发生什么 |
|---|---|---|
| R1 | **框架只推荐，不驱动** | 自动散会／自动收束会让「集体决定」变成框架独断，会议失去意义；同时违反用户对框架角色的根本设定 |
| R2 | **沉默 ≠ 同意**（禁止任何折算） | 一旦把沉默折算为同意，任何门槛都可被「不说话」的人数注水，结论强度失真且不可审计 |
| R3 | **票与发言分离** | 混同后「谁说过什么」会变成票权，辩论变成拉票，且列席者会获得事实上的表决权 |
| R4 | **chair-first**（阶段迁移与收束由院士触发） | 若由框架或其他成员推进阶段，会出现「无人主持的收束」，决议来源不清 |
| R5 | **主持不额外加权** | 主持既是程序裁决者又是加权投票者，则程序异议形同虚设（C5） |
| R6 | **真值不越界**（辩论只收敛意见） | 辩论宣布真伪会架空验证制度，使「已验证」失去唯一来源 |
| R7 | **可审计／可追溯** | 无稳定标识与留档则决议不可引用，复议与追责都无从谈起 |
| R8 | **贴合现实优先** | 照搬议事规则会产出无法执行的流程，成员会用「跳过流程」来自救 |
| R9 | **程序性表决未达门槛一律「未决」** | 若允许"未达门槛"被平均或折算成结论，任何程序性表决都可能被悄悄放大成实体定论，决议是否成立将不可审计（C3 分层原则的硬约束面） |
| R10（本章第 7.2 节） | **「过程判定」与「结束裁定」必须分离** | 讨论过程中的票数观察只是"当时票数的描述"，不得据此停止/收束/切换阶段；停止只可能来自院士显式操作或"具名广播的触界"；只有辩论结束时才请每位成员给出最终评判并聚合；该结果**不构成研究真值**（正文见 第 7 节） |

| **G4**（原 R4） | 同一议题同时出现在两场会议 | **已裁定（决议类互斥、讨论类可并行）**：**决议类**（会产出实体定论／表决，如结题表决、以辩论收敛结论者）在**同一议题上同一时刻只允许一场**；冲突时**以先开者为准**（后开者**不得**继续表决流程），并**显式通知后开者及其主办方**——**具名**且**记入后开者的纪要**，不得静默；**讨论类**（状况同步／学术讨论／任务规划／组织调整）**可并行**，但**并行会议不得就同一议题产出实体定论**。理由：「同一问题两套结论」是研究组织最危险的失真之一 | **已裁定** |
| **G5**（原 R5） | 代理成员的「知情权」边界 | **已裁定（默认最小必要知情，全文按需索取）**：默认主动推送只限**与本人相关**者（本人任务／被指派、被点名或被引用、涉及本人的表决与决议、本人所属议题的结论）；**全文与历史可主动索取／读取**——知情权**不被剥夺**，只是**不强制推送**；**私聊内容永不默认转发**给第三人（与 D6 一致）；**跨会议只引上次决议**。理由：贴合「列席与在册各有知情范围」，避免代理上下文被无关材料灌满 | **已裁定** |

### 4.3 U3／U4／U5 的裁定（**已定**）
- **U3（不记名的「更强复议门槛」强度）**：定为**可调政策**，但设**下限**——**不得低于该会议形成正式结论所需的标准**（不记名表决后翻案，门槛**只升不降**）；具体数值留作日后参数化。
- **U4（降级出口中「取平均」与「归档」谁选）**：**由院士提出、会议以动议＋多数决定**；**若无人动议** ⇒ 默认落到「**取平均并标注『未定论』**」（与 D4 一致）；**归档**是**仅当**议题被判定「证据不足、不宜给数值」时的出口。
- **U5（术语统一）**：以 **「同一会议」（同一会议实体的整个生命周期）** 为唯一单位；**D5 的复议与 D6 的引用都按「同一会议」判定**；「**会期**」一词在定稿中**不再单独使用**。
- **「取平均」的场合互指（防张冠李戴）**：两个「取平均」**不是同一件事**。**场合一（允许）**＝**辩论结束后的最终评判聚合**：有 m 个 1（或 0）且无反例 ⇒ 定论；**否则取平均并更新概率估计**（＝意见收敛，见 **R10 第 5 条**）。**场合二（禁止）**＝**程序性表决**：**未达门槛／未达法定人数 ⇒ 一律记「未决」**，**不得**用平均或其它算术手段替代其结论（＝**C3／R9**）。**判据一句话**：**看这次表决是在收敛意见，还是在决定程序／议题是否成立**。并与 **D4 的预设出口**互指：触界后按规则「**取平均并标注『未定论』**」或**归档**——属**场合一的延伸**，**不是场合二的替代**。

## 6. 移交实现（业务层）（对应 R1–R10：本节的"硬约束/可调政策"分层即红线的落地分类）

1. **R2＋C1（沉默语义）**：它是其余一切的计量基础，先钉死「未表态／无异议」两个词。

## 8. 追加裁定（用户点名两件；明文定稿）

### 7.1 投票板与规则的「支持性确认」——**平台必须支持院士自行设定**（对应 05 第 2 节 B10（记名/不记名；**不占用 D2 编号**）、D3 门槛与"未答不计分母"、D5/D5a 复议、U3 门槛只升不降）
业务要求（不含实现细节）：**必须支持**院士**自行设定**下列各项，并在**投票开始前**对外可见：
1. **各选项内容**（可增删改；选项文本由院士定）；
2. **单选／多选**；
3. **最多选几票**；
4. **至少选几票**；
5. **最少收集几票**（＝**本次投票是否成立**的门槛）；
6. 一并确认：**记名／不记名**、**是否允许弃权**、**是否允许改票**——**截止前**可改；**生效后**只能走**复议**（与 G2 生效时点、复议条款一致）。

**分层语义（重申，与既有裁定一致）**：**法定人数**（结题门）与**本次投票的「最少收集票」**（该次投票是否成立）是**两个不同的门槛**，**不得混用**。不满足「最少收集票」⇒ **该次投票不形成结论**，**不得**据剩余票推断。

### 7.2 新红线 R10 ——「过程判定」与「结束裁定」必须分离（七条正文）
1. **辩论／讨论过程中**，任何「**m 个 1（或 0）且无 0（或 1）**（允许介于 0 与 1 的概率估计）」的观察**只是当时票数的描述** ⇒ **不得**据此**停止、收束、切换阶段或改变流程**；**是否继续辩论，只由院士决定**。
   *违反了会发生什么*：过程票数会变成"自动收束器"，辩论被中途掐断，结论来源不可回溯，同时架空 R1（框架只推荐不驱动）与 R4（chair-first）。
2. **停止只可能来自两处**：**(a) 院士显式操作**（结束辩论／收束／散会）；**(b) 触界**（章程／参数化的**有界兜底**，且触界**必须具名广播**，院士可撤销或续期）。
   *违反了会发生什么*：出现"无人主持的停止"，无法追责，且与 D4（延长有界、预设出口）冲突。
3. 过程性计票若被展示 ⇒ **必须明确标注「尚未生效／仅供参考」**，且**不得**在任何提示词或纪要里写成"结论／通过／已定"。
   *违反了会发生什么*：读者会把过程数字当成决议，"伪共识"由此产生（与 R2 同族）。
4. **只有在辩论结束之时**（院士结束或触界后）⇒ 框架**同时**请**每位成员**给出**最终评判结果**（含布尔概率估计＋理由）。
   *违反了会发生什么*：成员在不知"已结束"的情况下给出终值，票面语义不齐，聚合结果不可比。
5. **聚合规则**：若有 **m 个 1（或 0）且无 0（或 1）**（允许介于 0 与 1 的概率估计）⇒ **最终结果记为 1（或 0）**；**否则求平均值、更新概率估计结果**；**未达参与／门槛**的情形按既有裁定处理（**未决**，**不得**用平均替代程序性结论，见 R9）。
   *违反了会发生什么*：意见强度与决议成立被混为一谈，结论强度被悄悄放大（与 C3 分层冲突）。
6. **广播口径**：框架把「**根据研究所规则，由于…，故最终布尔概率结果更新至…（如 0.6）／判定结果为…（1／0）**」发给**各辩论者**；其中「**由于…**」**必须写出实际依据**（票型、门槛、是否取平均）。
   *违反了会发生什么*：不可审计、不可复议，且与 R7（可审计可追溯）冲突。
7. **该最终结果不构成研究真值**（与 R6 一致）：它只是**意见收敛结果**；**真值仍由验证制度裁定**。
   *违反了会发生什么*：辩论结论冒充已验证结论，"已验证"失去唯一来源（与 R6 直接冲突）。

**交叉引用**：与 **R1**（框架只推荐不驱动）——过程票数不得驱动流程；与 **R2**（沉默≠同意）——过程展示不得折算为同意；与 **R9**（程序性表决未达门槛一律未决）——未达门槛不用平均替代；与 **D4**（延长有界／预设出口）——触界属有界兜底且须具名广播；与 **G2**（公告即生效）——结果只有在"结束裁定＋广播"之后才生效，过程数字一律未生效。
