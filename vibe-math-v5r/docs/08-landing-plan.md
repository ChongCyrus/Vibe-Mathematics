## 3. 落地顺序（5 期，每期可独立交付）

**必须一次到位（不可分期）**：**票/发言分离**（#13）、**沉默≠同意 的聚合口径**（#15 聚合半）、**未投票阻塞结题**（#16）——三者在语义上互为前提，分批会造成"同一会议两套口径"的历史包袱（v4/v5 `quorumMode` `L963` 就是先例）。

| 期 | 范围 | 验收判据 | 风险 |
|---|---|---|---|
| **① 命令目录与权限骨架** | A#3、A#7、A#8 | 四个命令（开会/辩论/表决/平常会议）都能开会且**只有院士**能开/能结束；临时授权**可回收**且回收后无残留票权；未授权主体调用被**具名**拒绝 | 权限收紧过头 ⇒ 既有 run 被拒（用 `quorumMode` 兼容期）；授权泄漏（§7-3） |
| **② 群聊两模式＋引用** | B#9、B#10 | 单次模式：每人**恰一条**（超出者被拒并具名）；轮流模式：每条发言**引用**上一条且引用完整性可校验（悬空引用被拒） | 无界群聊刷爆上下文（§7-4）；引用校验做成"仅提示词"⇒ 必须结构校验 |
| **③ 投票板** | B#12、#13/#15/#16 | 门槛按 `quorumM()`（`L1416`）判定；**未投票阻塞结题**；**沉默不计票**；票与服务发言在纪要中**分区**呈现 | 规则歧义（§7-5）；与 `verify` 既有票**双轨**（须共用聚合入口） |
| **④ 类型字段与流程推荐** | A#4、A#5、A#6、B#17/#18 | 类型字段**驱动**流程（改字段 ⇒ 流程变）；推荐可被院士**覆盖**且覆盖被记录；无推荐时按兜底收束 | 推荐被做成强制（§7-1）；类型目录膨胀 |
| **⑤ 辩论聚合与广播** | B#14、#18 | m 个 1/0 且**无反例** ⇒ 定论；否则**平均**；广播含"根据研究所规则，由于…"且规则**可解析引用** | 聚合口径与 `quorumMode` 冲突（§6）；广播措辞无法定位规则 |

## 4. 守卫与具名红清单（按"静态优先"排序）

> 三形态沿用项目惯例：源码级（随仓 `tests/*.mjs` 断言）→ 变异族（`tests/*.mutants.mjs`）→ 套件内 `--self-probe`。
> **每条新断言都要一条单点具名红**；**先绿后变异红**（红上再红的变异不算证据）。新增工作点应尽量折进既有套件，避免作业数漂移。

| 期 | 断言（源码级/行为级/E2E） | 单点变异（具名红） |
|---|---|---|
| ① | 源码级：命令目录表存在且四命令齐；权限检查函数**先于** `beginMeeting`（`L5291`）生效；授权台账有过期字段 | 变异：删掉权限检查调用 ⇒ 断言名"只有院士能开会"红；变异：令授权永不过期 ⇒ "临时授权可回收"红 |
| ② | 行为级：单次模式第二次发言被拒（结构化错误码，非提示词）；E2E：轮流模式每条含引用且悬空引用被拒 | 变异：去掉配额判断 ⇒ "每人恰一条"红；变异：把引用校验降级为提示词 ⇒ "悬空引用被拒"红 |
| ③ | 行为级：**沉默不计票**（0 票）；**未投票 ⇒ 不得结题**（具名阻塞）；门槛用 `quorumM()` 同源 | 变异：把沉默当赞成票 ⇒ "沉默≠同意"红；变异：允许带未投票结题 ⇒ "未投票阻塞"红；变异：门槛改常数 ⇒ "门槛同源"红 |
| ④ | 源码级：类型字段出现在**推荐输入**与**流程选择**两处；行为级：院士覆盖被记录；E2E：无推荐仍收束 | 变异：硬编码流程忽略类型 ⇒ "类型驱动"红；变异：把推荐写成强制（覆盖被忽略）⇒ "可覆盖"红 |
| ⑤ | 行为级：m 个 1/0 无反例 ⇒ 定论；有反例 ⇒ 平均（两个方向各一例）；广播含规则引用 | 变异：去掉"无反例"判据 ⇒ 定论分支红；变异：有反例仍下定论 ⇒ 平均分支红；变异：广播去掉规则引用 ⇒ 广播断言红 |

## 5. 真机复验判据（SLV 配方要点）

沿用硬预算模板：**配置+状态 ≤50k tokens**、**v5 启动+1 轮 ≤250k**、**v4 启动+1 轮 ≤900k**、**双常驻会议 ≤600k**、总预算 **≤2.5M**；**超时/触顶 = NON-RESULT，绝不判通过**；清理只清**自己**的 `~/.dsh/sessions/<escaped-cwd>/<sessionId>/` 与自身 id 的 `session_projcache`。

| 类型 | 可判定判据（2–4 条） | 预算/墙钟建议 |
|---|---|---|
| **辩论** | ① 开局"单次群聊"：**每人恰一条**（比对纪要发言者集合与在场成员集合） ② 轮流辩论**每条含引用**（引用目标存在） ③ 结束时**每人给出概率估计**（纪要中每人 0–1 数值） ④ 广播含"**根据研究所规则，由于…**"且规则可定位 | v5 单次辩论：≤250k / ≤8 min；辩论+广播：≤600k / ≤15 min |
| **平常会议** | ① **无人举手也能顺利收束**（无超时错误） ② 纪要具名记下"已获得机会、选择未发言"（对应 `L2610`） ③ 收束后 durable OPEN 标记清除（`L5555`） | ≤250k / ≤10 min（`meetingHardLimitMs` 默认 30 min，测试内可钳到 5 min） |
| **表决** | ① 门槛 = `quorumM()`（`L1416`）而非硬编码 ② **沉默不产生票**（票数等于显式投票人数） ③ 有未投票者 ⇒ **结题被具名阻塞** ④ 达到门槛且无反例 ⇒ 定论，否则平均 | ≤250k / ≤10 min |
| **兼容复验** | 旧 `institute.v5state.json`（含 `meetingOpen`，`L480`）能被读入且会议续跑；v4 口径 run 不被 v5 语义误伤（`L963`） | 各 ≤100k |

## 6. 兼容与迁移

- **参数**：新增类型/流程相关参数应加进 v5 参数面并同步 `docs/parameter-schema.md` 与冻结键集（否则 `PARAM_PROPS_KEYS` 类守卫会红）。`quorumMode` 现有两值（v5 `m-unanimous` / v4 legacy `all-unanimous`，`L963`）**保留**，不要静默改默认值。
- **数据格式**：`Shared/Meetings/<id>.md` 纪要格式**向后兼容**（新增分区：发言区/投票区），旧纪要可读且不被重写；`paper.meta.json` 式的伴生元数据若扩展，需保持"缺字段=旧版本"的读法。
- **目录结构**：建议新状态一律落在既有 institute 目录树内（**绝不写工作区之外**）；新文件命名走 `makeIdAllocator`（`L1387` 注释）以免并发丢 id。
- **旧 `v5state.json`**：新增字段必须**可选**且缺省有合理默认（`meetingOpen` 的补丁合并 `L574` 是范例）；**不需要**版本号口径变更即可读旧文件；若确实要迁移，走"读旧→写新→保留旧备份"的一次性迁移，且必须有守卫与具名红。
- **v2/v3/v4 影响**：v4 有 `all-unanimous` legacy（`L963`）与自己的 `paperPrompt`；**是否同步四预设**（命令目录/类型字段/投票板）**待用户决定**。建议：先只落 v5，其他三个仅保持"不误伤"（不新增语义分歧）。
