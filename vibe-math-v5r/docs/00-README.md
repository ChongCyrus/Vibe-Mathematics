# 第 00 章 · 手册总览

本手册是 v5r 会议与协作平台的统一读本：把定稿、章程、接口、专题与落地合成一条可顺序阅读、可逐条验收的路径。

> **硬性要求（三条）**
> 1. **v5r 是 v5 的重构版**，不是另一套产品；读本中一切机制以 v5r 为准。
> 2. `LEGACY-v5-实现方案（仅供参考）.md` **仅供参考，不是规格**；与它冲突之处一律以本手册第 02 章（定稿）与章程为准。
> 3. **权威基线 ＝ 定稿 ＋ 章程**；其余章节只在各自范围内补充说明，不得改写定稿结论。


## 1. 阅读顺序

03 接口 → 09 实现 → 02 规则 → 01 章程 → 04／05／06／07 专题 → 08 落地 → 10 守卫与验收 → 11 附录。

先读接口与实现，是为了知道这套东西**长什么样、能做什么**；再读规则与章程，是为了知道**什么必须做、什么禁止做**；专题与落地给出**怎么用、怎么推**；最后用守卫与验收核对**是否做到**，附录只作底稿索引。

## 3. 权威顺序

- **02 章（规则定稿）** 与 **01 章（章程）** 是权威基线：一切规则的冲突以它们为准。
- **03 章（接口）** 与 **09 章（实现）** 只说明**形态与边界**：它们描述"是什么、在哪"，不得据以改写规则，也不得把实现细节升格为规则。
- **04–07 章（专题）** 是同一基线的展开与补充；与基线冲突时无效。
- **08 章（落地）** 只回答"怎么推"；**10 章（守卫与验收）** 只回答"是否做到"；**11 章（附录）** 只作索引，不产生新规则。

## 4. 编号与引用约定

- 章标题统一为 `# 第 NN 章 · <中文标题>`；章内小节统一从 `## 1.` 起编号。
- 章间引用**只指向本手册内的章节号**（如"见第 02 章"），不引用手册外的材料。
- 除 11 章（附录）外，正文不出现底稿名称；附录只索引，不内联底稿全文。
