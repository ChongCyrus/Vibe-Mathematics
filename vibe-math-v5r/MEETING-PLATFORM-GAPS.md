# 会议平台：对抗性查漏（现实制度 × 代理场景）

## 第一部分：漏掉的现实制度／环节（30 条）

> 每条四段：**制度名 → 现实怎么做 → 为什么重要 → 若不纳入会出什么问题**。

1. **动议与附议（motion & second）**
   现实：任何一个议题要先有人**正式提出**（动议），再由**另一人附议**才进入讨论；无附议则动议自然死亡，不占用会议时间。
   重要：它把"有人想谈"与"大家同意值得谈"分开，是会议时间的第一道过滤器。
   不纳入：任何一个成员随口一句就能把全体拖进一轮讨论，讨论量与发言权被最活跃者垄断。

2. **优先／程序性动议（privileged & subsidiary motions）**
   现实：休会、散会、延长、限制辩论、搁置、付委、结束辩论（previous question）各自有**固定的优先顺序**，可随时插队，且多数只需简单多数。
   重要：会议必须能在**不解决实体问题**的前提下改变自己的进程（否则开不完的会只能烂在那里）。
   不纳入：主持人只能"开/关"会议，遇到跑题或超时**没有合法动作**，只能硬拖到轮次上限。

3. **法定人数清点（call for quorum / roll call）**
   现实：议事前先清点在场人数，不足法定人数只能**休会或做程序动作**，不能表决实体问题；清点本身可被任一成员要求。
   重要：它把"能不能表决"与"有多少人愿意参加"绑定，防止少数人趁虚做决议。
   不纳入：异步在飞/未唤醒成员与"弃权"混为一谈，出现"两个人在场就替全所定论"。

4. **时间箱与发言配额（time box / speech quotas）**
   现实：每人每次发言限时（如 2 分钟）、同一议题每人发言次数上限（如两次）、可"把时间让给他人"。
   重要：这是把**有限时间**分配给**分歧最大**之处的最直接手段。
   不纳入：健谈成员吃掉全部预算，安静成员永远排不上；总时长不可预测。

5. **议程的提出与通过（agenda adoption）**
   现实：开会第一件事是**通过议程**本身（可增删、可调序、可设时限），之后任何偏离议程都要经表决。
   重要：议程是把"主办方想谈什么"与"与会者认不认这个谈法"分开的唯一载体。
   不纳入：院士定的题目/流程既是提案又是裁判，成员只能接受或拒绝整场会，无法局部修正。

6. **议题的合并与拆分（combine / divide the question）**
   现实：可把一个动议拆成几部分分别表决，也可把相关动议合并审议。
   重要：很多僵局其实是**打包**造成的——某条能过，只因为和一条不能过的绑在一起。
   不纳入：表决只能整体真/假，成员被迫对混合命题投出言不由衷的票。

7. **修正案（amendments，含"友好修正"）**
   现实：先表决修正案，再表决（修正后的）主动议；提案人接受的小改动走"友好修正"不必表决。
   重要：会议产出**文字**，修正案是让文字收敛的正常机制。
   不纳入：要么原样通过、要么全盘否决，逼出"投反对但心里同意 90%"的失真票。

8. **表决方式：记名 vs 不记名（roll-call vs secret ballot）**
   现实：默认记名（可入纪要）；涉及人事/敏感事项才不记名，且**"进行了不记名表决"这一事实**要记录。
   重要：表决方式本身是一项**要表决的动议**，因为它决定事后能否追责与复核。
   不纳入：把"举手表决"当默认 ⇒ 与"可审计"直接冲突；反之全程强制记名 ⇒ 敏感议题上成员不敢表达真实判断。

9. **弃权与"到场但不投"**
   现实：弃权**不计入**多数门槛的分母（或按章程明示计入），且与缺席区分记录。
   重要：门槛的语义（m 人一致）取决于分母定义，含混会让同一份票型算出两个结论。
   不纳入："没投"既可能被算成同意，也可能被算成反对，两种都能被用来制造假多数。

10. **少数意见／异议记录（minority report / dissent）**
    现实：落败一方可要求把自己的理由**载入纪要**，附在决议之后。
    重要：反例是后续复议与纠错的第一手材料；没有它，错误结论会被"全体一致"的假象固化。
    不纳入：被否决的理由消失，下次犯同一个错要重新发现一遍。

11. **上次纪要确认（approval of minutes）**
    现实：每次会议的第一项实质议程是确认上次纪要（只改事实错误，不改结论）。
    重要：它给出"跨会连续记忆"的合法性来源。
    不纳入：跨会话的结论、任务、承诺没有可回溯的凭据，成员各记各的版本。

12. **行动项与执行跟踪（action items, owners, due dates）**
    现实：决议之后逐条列出**谁、做什么、何时**，下次会议先检查上次行动项。
    重要：没有执行跟踪，会议只是"观点交换"；跟踪项是"会开完了吗"的唯一证据。
    不纳入：任务板与会议决议脱钩，会开得再漂亮也不产出可检验的进展。

13. **列席／观察员（observers without vote）**
    现实：可邀请外部或非表决成员列席，**可发言不可表决**。
    重要：把"信息来源"与"表决权"分离，是吸收临时工/外部意见的正规通道。
    不纳入：临时工要么完全隔离、要么被默认为表决者，两种都与"有表决权者 m"的定义冲突。

14. **回避与利益披露（recusal / conflict of interest）**
    现实：与议题有直接利益者应披露并回避投票（至少记录在案）。
    重要：在代理场景里"利益"= 自己写过的成果、自己提的命题——**审自己**是天然的利益冲突。
    不纳入：命题作者既提案又表决又定稿，结论的独立性无法向用户交代。

15. **主持中立与主持权轮值（chair neutrality / rotation）**
    现实：主持人一般不参与辩论、只在程序问题上裁决；重大组织可轮值或设"中立主持"。
    重要：主持权的正当性来自"不偏袒"，而不是来自职位高低。
    不纳入：院士既是主办方又参与实体判断时，"程序裁决"与"实体主张"混为一谈，成员无处申诉。

16. **主持裁决与申诉（ruling of the chair & appeal）**
    现实：任何成员可对主持的程序裁决提出申诉，由**全体**（主持人可回避）表决推翻。
    重要：这是会议内部唯一的"对主持人的制衡"。
    不纳入：流程由院士单方解释，成员对"为什么这次不算数"没有救济途径。

17. **复议／重审（reconsider / rescind）**
    现实：在特定条件下（同一会期、由当初胜方之一提出）可动议重新审议已通过的决议。
    重要：它允许"发现新证据后改主意"，而不必假装当初就错了。
    不纳入：结论一旦落盘就不可逆，新反例只能靠"再提一个对象"绕开，档案里留下两套互相矛盾的结论。

18. **动议撤回（withdrawal of a motion）**
    现实：提案人可在表决前撤回（若已被修正或已付委，需会议同意）。
    重要：防止"提了就得投"逼出无意义的表决。
    不纳入：成员一旦提出议题就必须走完全程，任何试探性提案都变成承诺。

19. **搁置与"带出（take from the table）"**
    现实：可暂时搁置议题，日后再取出继续，无需重新走完整流程。
    重要：给"时机不对"的议题一个低成本去处，与"否决"区分开。
    不纳入：要么立刻表决、要么彻底丢弃，中间地带缺失。

20. **会议通知与议程分发时限（notice）**
    现实：临时会需提前通知（含议程与材料），否则程序不合法；例会按固定节奏。
    重要：异步成员需要**准备时间**，否则只有"随时在线"的人能真正参与。
    不纳入：在飞/休眠成员醒来时议题已经表决完，参与度随时间衰减。

21. **发言登记与主持人认可（speaker list / recognition）**
    现实：要发言先登记（举手），主持人按名单点名；同一议题上主张不同者交替发言。
    重要：这是把"谁能说话"从"谁嗓门大/回复快"变成"排队"的关键机制。
    不纳入：抢答式对话里，先出现的观点反复被重复，后出现的论证没有机会被听见。

22. **会议级别与授权链（session levels & delegation）**
    现实：所务会/专题会/小组会权限不同；上级可授权下级决定，也可保留终审。
    重要：不是每件事都值得全所开会；分级是"成本与重要性成比例"的制度化。
    不纳入：要么所有事都全所表决（臃肿），要么所有事都由院士独断（失去 m 门槛的意义）。

23. **平票与门槛未达的处理规则（tie / threshold failure）**
    现实：章程必须事先写明平票怎么办（否决、主持人决定、或按未通过处理）与"未达门槛"的后果。
    重要：它是"没有结论"这一合法结果的定义；否则系统会在无结论时自行编一个。
    不纳入：未达 m 时"取平均并更新"与"记为未定论"的边界模糊，用户看到的结论强度被悄悄放大。

24. **表决前的最后陈述与"结束辩论"（closing statements / previous question）**
    现实：结束辩论前，双方各获一次（或固定时长）最后陈述；随后立即表决，不再新增论据。
    重要：它让"停止讨论"成为一个**可预期、对称**的动作，而不是突袭。
    不纳入：多数方可随时掐断辩论，少数方的关键反例永远来不及说完。

25. **唱票与复核（vote counting & recount）**
    现实：当场唱票、可由监票人复核；票数记录进纪要，任何人可事后核对。
    重要：代理场景里"计票"是纯函数，但**输入集合**（谁有资格、哪些票有效）必须可复核。
    不纳入：票数无法复算，任何"m 个 1"都可能被质疑；用户只能信框架自报。

26. **不记名与"可审计"的边界（auditability boundary）**
    现实：不记名表决只登记"票数与结果"，不登记票面归属；记名表决登记到人。
    重要：必须**事先**选定，事后不得两头都要。
    不纳入：既要求可审计又要求不记名，最终是"框架知道是谁、用户不知道"，信任错位。

27. **缺席、代理与通讯表决（absentee / proxy / remote voting）**
    现实：允许缺席者书面/通讯投票或委托他人，须章程明示；否则缺席即视为未参与。
    重要：代理场景天生异步，"到场"必须被重新定义为"在可表决集合内且能应答"。
    不纳入：异步成员要么被算作弃权、要么被算作反对，两种都会被用来凑门槛。

28. **连续流会与"议题枯竭"处理（repeated failure / deadlock）**
    现实：若反复无法表决或反复未达门槛，章程给出降级路径（降门槛、交上级、或明确归档为未决）。
    重要：系统必须**有出口**，否则一次卡死就是永久占用会议资源。
    不纳入：议题永久挂在"进行中"，调度器反复唤醒，run 时间被无声耗尽。

29. **会议记录人／秘书角色（secretary）**
    现实：由非主持者记录会议纪要（议程、动议、票数、决议、行动项），对内容负责。
    重要：记录角色是"过程可审计"的物理载体，且与主持分离避免自证。
    不纳入：主持人既组织又记录，"纪要"退化为主持人的叙述，失去交叉验证。

30. **会后公告、生效时间与档案检索（publication, effective date, archive）**
    现实：决议在公告后（或指定时间）生效；全过程归档并可按议题/日期/提案人检索。
    重要："根据研究所规则，由于…"这句话要能被**引用**，就必须有稳定的决议标识与出处。
    不纳入：广播一句话就完事，后续成员无法引用、无法核对、无法知道哪条规则支撑了结论。

## 第二部分："想歪了"的地方（13 条）

> 每条：**风险 → 建议的现实折中**。

1. **无限自由辩论 ⇒ 上下文爆炸、成本与噪声失控。**
   → 折中：**辩论有轮次上限 + 每轮每人一次发言配额**；只允许提交**增量论据**（重复既有论据不占新额度）；每轮结束产出**压缩纪要**（结论+未决点+反例清单）供下一轮只读引用。

2. **默认"人人必须发言" ⇒ 冷场与凑数。**
   → 折中：发言**自愿**，但设"沉默即视为对当前提案无异议"的**显式**通道（并在纪要里写明"未发言者视为无异议"），同时保证沉默**不**提升结论强度。

3. **把"物理在场"当默认 ⇒ 忽略异步在飞成员。**
   → 折中：以**可表决集合 + 已答/未答**建模；未答者超时按章程明示为弃权（不计分母）而非反对；清点时**必须**列出未答名单。

4. **把"举手表决"当默认 ⇒ 与可审计冲突。**
   → 折中：默认**记名**（票面入纪要）；仅对敏感议题可选不记名，且记录"本次为不记名"这一事实与票数；两种方式的结论强度**不同**（不记名结论在复议时需更强门槛）。

5. **"主持人可随时延长"做成无限延长 ⇒ 拖死 run。**
   → 折中：延长需**动议 + 多数**且受**次数与总时长**双重上限；到期自动落到章程预设出口（取平均并标"未定论"或直接归档），**不允许**静默续期。

6. **把院士当"永远中立的主持人" ⇒ 与"院士可定题目/内容/流程"冲突。**
   → 折中：明确**主办方与主持人两种身份**：院士立题/设议程=主办方；程序裁决=主持权，且**程序裁决可被申诉**。院士不因主持而获得实体票的额外权重（现有"不额外计票权"应写进哲学层）。

7. **自由 @引用无限制 ⇒ 引用链爆炸。**
   → 折中：引用只保留**被引用结论的摘要 + 稳定指针**（决议/卡片 id），不搬原文；同一目标被多次引用时合并；引用深度设上限。

8. **表决前要求每人给"理由" ⇒ 冗长且大量重复。**
   → 折中：理由**限长**；与既有理由实质重复者可只标注"同 id"；只在**改变了判断**时才要求新理由（比例估计的变化本身就是信息）。

9. **把少数意见当噪声 ⇒ 丢掉关键反例。**
   → 折中：少数意见**强制入档**（作为决议的附属记录），并作为**复议触发条件**之一：出现新反例即可低成本复议，而不是重开一个新对象。

10. **把"会议"当唯一决策渠道 ⇒ 与异步/超时冲突。**
    → 折中：哲学层显式区分**会内决定/会外协同**：实体定论只在会议内产生；任务认领、资料交换、进度汇报走会外；紧急情况允许"临时会"但需事后追认。

11. **"到场即算"的法定人数 ⇒ 在飞成员被误判缺席。**
    → 折中：法定人数按**已就位 + 可被唤醒**计算，并区分"唤醒失败"与"拒绝参加"；唤醒失败不得被当作反对票。

12. **所有会议都走完整流程（动议/附议/纪要确认/唱票）⇒ 仪式过重。**
    → 折中：会议**分级**：正式议题走全流程；同步例会/进度会走简流程（议程+轮询+行动项），但**简流程不得产出实体定论**。

13. **"框架只推荐不强迫"被理解成"框架什么都建议一遍" ⇒ 建议噪声。**
    → 折中：推荐**一句一条、可执行、可拒绝**（明确代价），且**不得**在成员未请求时反复重申；推荐与事实陈述在措辞上必须可区分。

## 第三部分：判断"是否真的贴合现实"的自检判据（8 条）

1. **主持人直觉判据**：把这条机制念给一个真实会议主持人听，他会不会觉得**莫名其妙或多余**？会 ⇒ 要么删掉，要么补上它对应的现实制度。
2. **记录物判据**：这条机制在现实中对应哪件**记录物**（议程 / 纪要 / 决议 / 名单 / 唱票记录 / 行动项表）？找不到记录物 ⇒ 它不可审计，也就不可引用。
3. **缺席判据**：关键人缺席/超时/唤醒失败时，这条机制**退化到什么状态**？退化路径必须显式、且是现实中可接受的（弃权、休会、未定论），不能是"悄悄当成同意"。
4. **一句话复述判据**：结论能不能用"**根据研究所规则，由于…**"一句话复述，且这句话里的每个前提都能在记录物里指出来？不能 ⇒ 门槛或规则不清晰。
5. **少数方出口判据**：持异议者在这套机制里有没有现实对应的手段（载入少数意见 / 复议 / 申诉 / 撤回）？没有 ⇒ 该机制只服务多数，迟早骗过用户。
6. **成本有界且成比例判据**：这一环节的代价（轮次、发言数、引用深度、上下文）是否有上限，且上限与**议题重要性**成比例？无上限 ⇒ 它迟早拖垮一次 run。
7. **单一权威判据**：与章程/表决规则/任务板冲突时，谁优先？若说不出唯一权威源，这条机制就会在实现层"两处各说一套"。
8. **可不开会判据**：不启用这条机制（院士不开会、成员不发言、不投票）时，研究所会不会**坏掉**？会 ⇒ 它被设计成了强制流程，违背"默认院士驱动、框架只推荐"的口径。
