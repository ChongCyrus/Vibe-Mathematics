# 05 · **已知债务与已裁定不做的事**（★ 定稿最需要诚实的一卷）

> ★ **为什么单独一卷**：★ 用户对定稿的要求里有一条：★ **"不包含未做的、与实际不符的内容"**。
> ★ **这一卷就是那条要求的机制**：★ **把所有"没做成"的东西【逐条具名】**，★ 让读者**不会把"没说"当成"没做"**，★ 也不会把"说了"当成"做了"。
> ★ **三条写作规矩**：★ ① **每一条都写明【为什么没做/没验】**；★ ② **写明【要它成立需要什么】**；★ ③ **绝不把"未验证"写成"没问题"**。
